# 自学习词表示例

这个文件是 `scripts/learn-lexicon.mjs` 的产物，放的是**从语料里挖出来的私房词**。

## 它是怎么来的

```bash
node scripts/learn-lexicon.mjs --apply
```

程序会读你的记忆库（`semantic.jsonl` + `episodic/*.jsonl`），用三个条件筛候选：

| 条件 | 判据 | 作用 |
|---|---|---|
| ① 见得够多 | 频次 ≥ 3 | 挡掉笔误和一次性说法 |
| ② 老在一起 | PMI ≥ 4.0 | 这几个字总是黏在一起 |
| ③ 前后能接别的字 | 左右邻熵 ≥ 0.9 | 它是完整单位，不是别的词的尾巴 |

然后去掉被更长词包住的子串（「肥鱼」被「大肥鱼」压掉）。

## 现在这份是什么

**这是一份示例，来自一个真实的陪伴型聊天机器人语料。**

里面混着两类词，正好说明这个机制能抓到什么：

- **技术词**：参考音频、显存、底模、整合包、系统代理、提示词 —— 因为它们聊的是本地 TTS 和模型训练
- **私房词**：大肥鱼、小鲸鱼、鲸鱼娘、老婆大人 —— 这些是通用词表里绝对没有的

## 换成你自己的

```bash
# 1. 把你的记忆库放好（或者让程序跑一段时间攒出语料）
# 2. 跑挖词
node scripts/learn-lexicon.mjs            # 先 dry-run 看看挖出什么
node scripts/learn-lexicon.mjs --apply    # 确认后写入

# 3. 跑测试确认没挖坏
npm test
```

挖完之后建议把你的 `data/jieba-learned.txt` 加进 `.gitignore`——里面可能有你不想公开的东西。

## 不想要它也行

删掉这个文件，`memory-lexicon.js` 会自动只用通用词表（10.9 万词），功能不受影响，只是不认识你的私房词了。
